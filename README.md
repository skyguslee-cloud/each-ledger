# 우리집 가계부 — 각자 가계부 버전

각자 자기 휴대폰에 가계부를 적고, **통합용 파일**을 한 사람에게 모아 가족 전체를 합쳐 보는 버전이에요.

- 저장: 이 휴대폰의 IndexedDB(`each-ledger`)에만 저장해요. 서버·계정·시트 연결이 없어요.
- 작은 설정값 접두어: localStorage `each-ledger:` (같은 github.io 주소의 다른 가계부와 섞이지 않게)
- 가족 통합: 더보기 → 가족 통합 보기 → **내 파일 보내기**(JSON, `kind: each-ledger-share`) → 받은 사람이 **받은 파일 넣기**.
  가계부마다 고유 id(`ledgerId`)가 있어서 같은 사람의 새 파일은 통째로 바뀌고, 더 예전 파일은 무시해요.
- 🎤 음성 입력: 브라우저 음성 인식(Web Speech API, `ko-KR`). 크롬(안드로이드·PC)·아이폰 사파리, https 주소, 인터넷이 필요해요.
  "어제 점심 김밥천국 만이천원"처럼 말하면 날짜·금액·분류·내용을 채우고, 사람이 확인한 뒤 저장해요.
- 바탕 코드: `offline-ledger`(구글 시트 버전)에서 시트 동기화·비밀번호·초대 링크를 뺀 것이에요.

테스트: 주소 뒤에 `?dev=a`, `?dev=b`를 붙이면 같은 브라우저 안에서 다른 사람 휴대폰처럼 따로 저장돼요.
